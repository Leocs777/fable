# Fable

Fable 是一个东方决策与居家运势 App 原型。一期目标不是把所有术数做满，而是验证三个问题：用户是否愿意使用、是否看得懂、是否愿意为更深解释付费。

## 目标市场

**海外华人，以及对中华文化感兴趣的非中文用户。** 不面向中国大陆发行。这个决定影响一切下游选择：

- 合规以 App Store / Google Play 全球政策 + GDPR / CCPA 为基准，不涉及大陆 App 备案与内容监管。
- 支付走 Apple / Google IAP，以美元定价（参考带：订阅 $7.99–14.99/月，单次报告 $2.99–9.99）。
- 语言：一期架构必须 i18n-ready。内测先简体中文，英文界面在一期内跟进（解释内容可先机器翻译 + 人工审校），繁体中文随后。英文版是触达"文化好奇型"用户的前提，不是远期选项。
- 获客锚点参考 Co-Star / The Pattern 的西方占星付费模式，而不是国内玄学平台。

## Product Idea

Fable 把传统术数体验拆成三个可验证模块：

- 问卦决策：高频入口，用户输入一个现实问题，通过三枚铜钱起卦获得简明结论、行动建议和风险提醒。
- 四柱八字：深度入口，用户输入出生信息，生成基础命盘、五行分布和主题解释。
- 风水 Lite：差异化入口，用户手动输入房间类型、朝向、门窗床桌位置，获得可执行的居家调整建议。

核心原则是"文化参考 + 行动建议"。内容不能只是玄学描述，每次结果都要给用户能马上理解和执行的下一步。

三个模块都是"用完即走"型，因此一期必须带一个轻量留存钩子：**每日一卦 / 今日宜忌卡片**（被验证过的同品类留存机制，Co-Star 的核心就是 daily push）。没有它，内测留存数据无法区分"产品不行"和"缺回访理由"。

## Design Philosophy

- 仪式感要服务决策：铜钱、天机盘、卦象动画用于建立沉浸感，但不能拖慢流程；仪式动画必须可跳过，并支持 Reduce Motion。
- 解释要白话：避免堆术语，优先输出一句话结论、局势解释和三条行动建议。
- AI 不直接算命：规则引擎负责排盘、起卦和结构化结果，AI 只负责解释与表达。
- 不制造确定性幻觉：低置信度信息要明确标注。
- 高风险问题在入口拦截，不是软化措辞：自伤/危机类问题直接拦截并提供求助资源，不进入起卦流程；医疗、法律、重大财务问题明确拒绝起卦并说明原因。八字"年度趋势"不得输出健康、财务的确定性断言。
- 隐私优先 + 数据最小化：出生信息、提问内容、户型数据都按敏感数据处理，必须支持删除和导出。调用 LLM 时只发送结构化排盘结果（四柱、十神、五行分布、卦象），永远不发送出生日期原文、出生地、地址。
- 先验证付费价值：免费版给核心结论，深度报告、追问和主题扩展作为付费验证点。"按深度收费"与"按次数收费（免费 N 次后付费）"是内测要 A/B 的两个假设，不预先定死。

## Current Prototype

当前原型位于 `fable/prototypes/wengua-tianji/`，是一个可本地运行的手机端 Web 原型。

已实现：

- 问卦首页、问题输入、常见问题 chip。
- **确定性六爻起卦引擎**：三枚铜钱掷六次、6/7/8/9 爻值、本卦/变卦/动爻、64 卦名查表（金钱卦正规流程，非随机模板）。
- 逐爻成卦动画：每掷显示三枚铜钱正反、爻型（少阳/少阴/老阳/老阴），自下而上实时成卦；点击任意处可跳过；`?slow=1` 可放慢评审。
- 结果页：本卦/变卦六爻图、动爻标红、爻名（初九/六二式）、问题回显、免责声明。
- **真实 AI 解读后端**：掷完卦后，后端把「用户问题 + 卦象 + 64 卦义知识库」一起交给 Claude（`claude-opus-4-8`，结构化输出）生成贴合问题的白话解读、3 条行动建议和风险提示；前端有 loading 骨架态。未配置 API key 时自动回退到本地示例文案并明确标注，不阻塞 demo。
- **入口安全分类**：危机类问题（自伤等）在后端直接拦截，返回本地化求助资源（如 988），不调模型、不起卦；高风险（医疗/法律/重大财务）由解读引擎转为安全反思。
- 深度报告抽屉、模拟付费墙、解锁后追问。
- 历史记录抽屉、记录查看、删除全部。
- 隐私同意抽屉和本地 consent 状态。
- 八字基础输入、时辰置信度、四柱和五行结果展示。
- 风水 Lite 手工输入、房间平面示意和不少于 5 条建议。

说明：卦象计算已是正式规则（可直接迁移到后端），但解释文案仍是原型示例（按卦名稳定取样），正式一期由"规则结果 + 知识库 + AI 解释"替换。八字四柱仍是静态演示数据。

## Run Locally

```bash
cd fable/prototypes/wengua-tianji

# 可选：启用真实 AI 解读（二选一）
export ANTHROPIC_API_KEY=sk-ant-...
# 或 cp config.local.example.json config.local.json 后填入 key

node server.mjs
```

启动时会打印 `AI interpret: enabled/DISABLED`。未配置 key 也能跑，问卦解读会回退到本地示例文案。

打开：

- 本机：`http://127.0.0.1:4174/`
- 手机：使用服务启动时打印的局域网地址，例如 `http://192.168.x.x:4174/`
- 评审用：`?state=casting` 直接进起卦，`?slow=1` 放慢动画，`?state=result` 直接看结果。

手机需要和电脑在同一个 Wi-Fi 下。想省钱可设 `FABLE_MODEL=claude-haiku-4-5`。

## Phase 1 Direction

一期按**分段验证**推进，每段结束有明确的继续/停止决策点，而不是三模块齐活再内测：

1. **阶段 A（先行）：问卦闭环。** 起卦规则（原型已完成计算层）、安全分类与入口拦截、AI 白话解释、历史记录、付费墙、每日一卦钩子、埋点。内测后看数据：首卦完成率、D7 留存、付费转化。
2. **决策点：** 数据达标才进阶段 B；不达标先迭代问卦或调整付费切分。
3. **阶段 B：八字承接深度付费。** 真太阳时、节气、四柱排盘规则层、置信度策略、主题卡。
4. **阶段 C：风水 Lite 差异化。** 补强手工输入体验，保存、收藏、分享卡。
5. **工程化迁移：** React Native + 后端规则引擎，i18n 架构从第一天就进（文案全部走 key，不硬编码中文）。
