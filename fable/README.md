# Fable

Fable 是一个面向中文用户的东方决策与居家运势 App 原型。一期目标不是把所有术数做满，而是验证三个问题：用户是否愿意使用、是否看得懂、是否愿意为更深解释付费。

## Product Idea

Fable 把传统术数体验拆成三个可验证模块：

- 问卦决策：高频入口，用户输入一个现实问题，通过三枚铜钱起卦获得简明结论、行动建议和风险提醒。
- 四柱八字：深度入口，用户输入出生信息，生成基础命盘、五行分布和主题解释。
- 风水 Lite：差异化入口，用户手动输入房间类型、朝向、门窗床桌位置，获得可执行的居家调整建议。

核心原则是“文化参考 + 行动建议”。内容不能只是玄学描述，每次结果都要给用户能马上理解和执行的下一步。

## Design Philosophy

- 仪式感要服务决策：铜钱、天机盘、卦象动画用于建立沉浸感，但不能拖慢流程。
- 解释要白话：避免堆术语，优先输出一句话结论、局势解释和三条行动建议。
- AI 不直接算命：规则引擎负责排盘、起卦和结构化结果，AI 只负责解释与表达。
- 不制造确定性幻觉：低置信度信息要明确标注，高风险问题要拦截或转为安全反思。
- 隐私优先：出生信息、提问内容、户型数据都按敏感数据处理，必须支持删除和后续导出。
- 先验证付费价值：免费版给核心结论，深度报告、追问和主题扩展作为付费验证点。

## Current Prototype

当前原型位于 `fable/prototypes/wengua-tianji/`，是一个可本地运行的手机端 Web 原型。

已实现：

- 问卦首页、问题输入、常见问题 chip。
- 天机盘放大和三枚铜钱掉落动画。
- 随机模拟卦象结果，用于原型测试。
- 深度报告抽屉、模拟付费墙、解锁后追问。
- 历史记录抽屉、记录查看、删除全部。
- 隐私同意抽屉和本地 consent 状态。
- 八字基础输入、时辰置信度、四柱和五行结果展示。
- 风水 Lite 手工输入、房间平面示意和不少于 5 条建议。

说明：当前问卦结果仍是原型级随机模板，不是正式周易规则引擎。正式一期需要接入六爻生成、本卦/变卦计算、动爻规则和可审校的解释模板。

## Run Locally

```bash
cd fable/prototypes/wengua-tianji
node server.mjs
```

打开：

- 本机：`http://127.0.0.1:4174/`
- 手机：使用服务启动时打印的局域网地址，例如 `http://192.168.x.x:4174/`

手机需要和电脑在同一个 Wi-Fi 下。

## Phase 1 Direction

一期建议继续按这个顺序推进：

1. 打磨问卦主流程，完成真实起卦规则、结果结构和安全分类。
2. 完成八字基础排盘的规则层，明确真太阳时、节气和未知时辰的置信度策略。
3. 补强风水 Lite 的手工输入体验，加入保存、收藏和分享卡。
4. 建立基础账号、隐私删除、历史记录和付费墙。
5. 准备 React Native + 后端规则引擎的正式工程化迁移。
