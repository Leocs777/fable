# Phase 1 启动包

本目录是“东方决策与居家运势 App”一期 MVP 的工作基准。后续产品、设计、后端、移动端、AI、测试和合规讨论，都先以这里的文档为准。

一期不是完整玄学平台，而是一个可运行、可内测、可验证付费价值的 MVP。目标是验证三个连在一起的产品假设：

- “问卦决策”能否成为高频入口。
- “四柱八字”能否承接深度解释和付费意愿。
- “风水 Lite”能否形成差异化，但不拖垮一期节奏。

## 前 10 个工作日要完成

- 冻结一期范围和明确不做事项。
- 做出“输入问题 -> 掷铜钱 -> 结果页”的可点击问卦主流程。
- 在开发前定义免费版和付费版结果差异。
- 确定初始数据实体和敏感数据处理规则。
- 准备问卦和八字计算 golden test。
- 准备医疗、法律、金融、自伤、暴力、操控关系等高风险问题红队用例。
- 定义第一版埋点事件和看板指标。
- 确定 TestFlight / 内测包的通过标准。

## 当前产品决定

- 做一个主 App，内含三个模块，不拆成三个独立 App。
- 先把问卦做成第一条完整用户旅程。
- 一期风水 Lite 只做手工输入和窄范围建议。
- 规则引擎负责计算，AI 只负责白话解释、组织结构和语气。
- 出生信息、提问、位置、户型、房间照片都按敏感信任数据处理。
- 隐私、删除、付费和评测从一期第一天就进入范围。
